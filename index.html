About

I'm a Senior User Assistance Developer at SAP, focused on SAP Asset Performance Management (APM). My work sits at the intersection of technical writing, data analysis, and AI documentation.

I don't just write documentation: I measure whether it works, use data to find what's missing, and build content that deflects support tickets before customers need to raise them. Most recently, I've been developing the documentation architecture for SAP APM's AI agents in Joule: responsible AI disclosures, scope and limitations, example prompts, and the trust infrastructure that enterprise AI documentation requires.

Using tools like Adobe Analytics, Self-Service Reporting, Task Completion Rate, and ISQM, I continuously surface insights that reveal where customers struggle, what content is missing, and where the next investment should go.
